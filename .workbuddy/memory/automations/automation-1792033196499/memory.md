## 执行要点（复用结论）
- 判断"已同步"不能只看 `updated_at`，必须同时看 **明细是否有内容**：`updated_at` 为今天但 `stats.by_status` 全是"未披露"= 接口整批失败。
- 快速体检：`stats.open_count + limit_count + pause_count > 0`，或 `universe` 字段含"复用上次代码表"字样。
- 服务在线时 POST `http://localhost:5001/api/sync`（异步，返回即走），随后轮询 `/api/meta` 的 `syncing`/`last_finish`；正常情况下 741 只约 30 秒完成。
- 服务离线才用 `sync_once.bat`（全量约 25–30 秒）。
- 天天基金 `fundmobapi.eastmoney.com` 偶发返回 HTML 页面（反爬/限流），表现为"非JSON响应"，通常过几小时后自愈。
